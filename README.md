# FlickPicks

**FlickPicks** is a social movie discovery and review app built using Kotlin and Jetpack Compose.  
Users can add friends, share reviews, and find movies to watch together through a collaborative swiping system.

[➡️ Watch the demo video here](https://student.cs.uwaterloo.ca/~cs346/1259/project/gallery.html)

---

## Features
- Rate and review movies
- Add friends and view their reviews
- Match with friends on movie choices using swipe-based liking
- Mobile-first design (Android app)

---

## Technologies Used
- Kotlin
- Jetpack Compose
- Firebase Authentication and Firestore
- Android Studio / AVD Emulator

---

## Getting Started
You can try FlickPicks by installing the APK on an Android device or emulator:
1. Download the `Final_Submission.apk` file from the [v1.1.0 Release](https://github.com/Jonny7171/flickpicks/releases/tag/v1.1.0).
2. Use Android Studio’s Device Manager to create an emulator (Pixel 8 or 9 recommended, API 33+).
3. Drag and drop the APK onto the running emulator to install.
4. Launch the app and enjoy FlickPicks!
